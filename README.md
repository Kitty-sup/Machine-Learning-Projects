# Indian Road Accident Analysis & Severity Prediction

## Overview
This project analyzes Indian road accident data and predicts accident severity using Machine Learning techniques.

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- One Hot Encoding
- Ordinal Encoding
- Logistic Regression
- Random Forest Classifier
- Model Evaluation

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
The dataset contains information about:
- City
- Weather
- Road Type
- Traffic Density
- Visibility
- Accident Severity

## Machine Learning Models
1. Logistic Regression
2. Random Forest Classifier

## Results
Random Forest performed better than Logistic Regression in predicting accident severity.
